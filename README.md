# BrightSmile Dental — demo business website

**Live demo:** https://brightsmile-dental-demo-omega.vercel.app

A sample business website (made-up clinic) built with **React 18 + Vite + Tailwind CSS 4**.
Used as portfolio work for the Fiverr Gig "I will build a modern responsive business website using React".

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build   # output in dist/
```

## Deploy to Vercel
Push this folder to GitHub, then import the repo in Vercel (framework: Vite). No settings needed.

## Structure
- `src/components/` — Navbar, Hero, Sections (Services, About, Reviews), Contact (form with validation), ui (Button, Container, SectionTitle)
- `src/data.js` — all text content in one place, easy to change for a new client
